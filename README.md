One sick-day line: a doctor's diagnosis of acute spreadsheet poisoning, cured only by 48 hours away from any cell that thinks it is a number — including the ones in the caller's own body. Running the program drops that line into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-200-character check.

## Run it

```sh
python3 main.py
```
